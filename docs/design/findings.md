# Findings log

One entry per mismatch between the draft contract and an existing model, or between the two
reference codebases. Append, never silently resolve. Contract changes must appear here.

**Verdicts:** `contract flaw` (change the contract), `model flaw` (fix the model),
`family-specific` (legitimate difference; keep in the family namespace; test: does it
matter for cross-family comparison? If not, it stays family-specific).

**Format:** `F-NNN | area | what differs | verdict | action | status`

Compare, and log every difference:

1. Variable names, units, and sign conventions (power, energy).
2. Parameter naming and structure.
3. Material classes (are they truly identical?) and melting-range smoothing (form and default

   storage side's discrete energy balance, or as `h*A*dT` on both sides?

   outlet temperature.

   finned-pipe definition.

11. Cut-off events and operating mode.
12. Default geometry, mesh, spatial methods, solver, and plot variables.
13. Test coverage: which existing tests have no counterpart in the other repo.
